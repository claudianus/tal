# 탈 ― 고양이 탈을 쓰지 않으면 방 밖에 나갈 수 없는 나는

브라우저에서 하는 이야기 게임. 프롤로그부터 에필로그까지, 엔딩 셋이 모두 들어 있다. 2시간 남짓.

중증 우울증, 자해의 흔적, 자살 사고, 가정폭력, 아동 학대의 정황, 학교폭력, 혐오 발언, 신상 털기가 나온다. 방법이나 도구는 어디에도 묘사하지 않는다. 시작 화면에서 장면 경고를 켤 수 있다.

마음이 힘들 때는 자살예방상담전화 109(24시간, 국번 없이).

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 연다. `index.html`을 파일로 직접 열면 돌아가지 않는다.

- 걷기: 방향키 (터치 화면에서는 왼쪽 아래 패드)
- 조사하기·넘기기: Z, 스페이스, 또는 화면을 누른다
- 선택: 누르거나 숫자 키
- 메뉴: 왼쪽 위 ≡ 또는 Esc
- `Ctrl`을 누르고 있으면 빨리 감긴다 (확인용)

## 구조

| 경로 | 내용 |
|---|---|
| `script/*.ink` | 대본. 태그 규칙은 `script/main.ink` 머리말에 있다 |
| `src/tables.ts` | 대본 태그 값 → 장면·효과음·연출 컷 |
| `src/pres.ts` | 화면에 남아 있는 상태 (저장·불러오기·빨리 감기가 같이 쓴다) |
| `src/engine.ts` | 대본을 한 줄씩 꺼내 연출한다 |
| `src/ui.ts`, `src/style.css` | 글, 선택지, 메신저·댓글·통화 화면 |
| `src/world.ts`, `src/maps.ts` | 걸어 다니는 맵 |
| `src/art/*.ts` | 도트 그림. 이미지 파일 없이 코드로 한 점씩 찍는다 |
| `src/scene.ts` | 맵이 없는 장면의 배경 |
| `src/audio.ts` | 소리 (Web Audio 합성) |
| `tools/` | 대본 컴파일, 태그 검사, 무작위 플레이 검사 |

## 검사

```bash
npm run build
```

대본을 컴파일하고, 대본의 모든 태그가 표에 있는지 확인하고, 타입을 검사한 뒤 `dist/`에 빌드한다.

대본이 바뀌면 이것도 돌린다.

```bash
node tools/walk.mjs 150    # 걸어 다니는 선택지가 모두 닿는지
node tools/sim.mjs 3000    # 무작위로 끝까지 플레이: 막히는 곳, 엔딩 비율, 엔딩마다 꼭 나와야 하는 줄
```

## 배포 (GitHub Pages)

`.github/workflows/pages.yml`이 들어 있다. 저장소의 Settings → Pages → Source를 "GitHub Actions"로 두면 `main`에 push할 때마다 빌드해서 올린다. `vite.config.ts`의 `base: './'` 덕분에 저장소 이름이 무엇이든 그대로 돌아간다.

## 만든 방법

기획과 방향은 rumadomo가 잡았다. 대본, 그림, 소리, 코드는 Claude(Anthropic의 AI)가 썼다. 이미지·음성 생성 모델은 쓰지 않았다. 그림은 `src/art/`의 코드가 한 점씩 찍고, 소리는 Web Audio로 그 자리에서 합성한다.
